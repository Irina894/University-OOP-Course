# 📘 Object-Oriented Programming (OOP) — University Course

This repository contains C# laboratory works completed during the **1st semester of the 2nd year** at Yuriy Fedkovych Chernivtsi National University. The course focuses on mastering the principles of OOP and advanced C# development.

## 🚀 Learning Objectives
The primary goal of these assignments was to transition from procedural programming to a robust object-oriented approach, focusing on:
- **Classes and Objects:** Defining custom types and managing state.
- **Encapsulation:** Using access modifiers and properties to protect data.
- **Inheritance & Polymorphism:** Creating hierarchical structures and reusable code.
- **Interfaces & Abstractions:** Designing flexible and decoupled systems.
- **Collections & LINQ:** Efficient data manipulation in .NET.

## 🛠 Tech Stack
- **Language:** C#
- **Platform:** .NET Core / .NET Framework
- **IDE:** Visual Studio
